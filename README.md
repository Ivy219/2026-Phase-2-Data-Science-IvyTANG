# 2026-Phase-2-Data-Science-IvyTANG
MSA Phase 2 projects

This repository showcases my Phase 2 projects completed during the MSA 2026 programme. The projects demonstrate practical applications of data preprocessing, exploratory data analysis, machine learning, and business analytics using real-world datasets.

## Repository Structure

### 📁 Part 1 – Furniture Sales Data Analysis
Exploratory data analysis on a retail furniture sales dataset.

**Key tasks**
- Data cleaning and preprocessing
- Feature engineering
- Exploratory data analysis (EDA)
- Sales trend analysis
- Correlation analysis
- Data visualization

**Tech stack**
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---
